# EnvDock 2.0.0 macOS 升级方案

日期：2026-11-22

## 范围

本次只针对 macOS 版本，基于 1.8.1 升级到 2.0.0。Windows 安装器、WebView2、DPAPI、NSIS 及 Windows 专属交付不在本次范围内。

目标平台是 macOS 13.7.8 Intel；同时保留 Apple Silicon（arm64）交叉构建能力。应用继续使用 Tauri 2、React、TypeScript、Rust、SQLite、macOS 登录钥匙串和 AES-256-GCM。

## 升级目标

- 统一前端、Tauri、Rust crate、锁文件和 macOS 文档的版本为 2.0.0。
- 修复 Node 25 测试环境对 jsdom `localStorage` 的覆盖问题，并让本机测试命令可重复运行。
- 隔离 Rust 测试对真实 macOS 登录钥匙串的依赖，避免无界面或钥匙串锁定时挂起。
- 降低编辑、响应解析和全局快捷键处理带来的重复渲染、临时数组和监听器开销。
- 增加渲染异常恢复入口、浅色主题对比度检查、CSP 基础加固和 macOS 打包配置断言。
- 记录验证结果和资源测量方法；未测量的启动耗时、峰值内存不作具体承诺。

## 低消耗约束

- 首屏继续按需加载设置、JSON 工具、开发工具和请求历史等非核心对话框。
- 全局快捷键只注册一个监听器，通过稳定引用读取最新状态。
- 工作台派生集合使用记忆化计算，避免每次编辑都重新扫描项目、环境、接口和关闭标签。
- 大 JSON 继续交给可取消 Worker；响应上限、历史上限和基准上限保持现有约束。
- 本机验证至少记录 `npm run build`、目标测试耗时，以及桌面版空闲和打开大 JSON 时的活动监视器内存读数。

## 验证门槛

提交前在 Intel Mac 依次执行：

```sh
npm ci
npx tsc -b
npm run test:ci
npm run test:packaging
cargo test --manifest-path src-tauri/Cargo.toml
npm run build
npm run build:mac
```

钥匙串集成测试单独执行：

```sh
cargo test --manifest-path src-tauri/Cargo.toml login_keychain_roundtrip -- --ignored
```

arm64 版本使用 `npm run build:mac:arm64` 生成；Intel Mac 只负责交叉编译，不能替代 M 系列设备上的实际启动验证。DMG 生成后检查 `hdiutil verify`、架构、应用包签名和版本字段，并确认旧 1.8.1 工作区可读取。

## 发布步骤

1. 通过上述本机验证并记录命令、耗时、失败重试和资源读数。
2. 生成 2.0.0 Intel/arm64 `.app`、`.dmg`、校验文件和安装说明；旧 1.8.1 交付物保留为历史材料，不改名冒充 2.0.0。
3. 更新 `RELEASE_NOTES_2.0.0.md`、macOS 安装说明和文档索引。
4. 复核 `git diff`、敏感数据处理、版本号同步和工作区迁移兼容性。
5. 在本地提交后推送 macOS 2.0.0 分支和标签到 GitHub；未得到实际构建与验证结果前不宣称已发布 DMG。

## 本机执行结果

- `npm ci`、`npx tsc -b`、`npm run build`、`npm run check:version`、`npm run test:packaging` 和 `npm audit --omit=dev` 通过；开发依赖审计也通过 0 漏洞检查。
- `npm run test:ci`：77 个文件、1102 个用例全部通过。
- `RUST_TEST_THREADS=1 sh scripts/mac.sh test`：155 个测试通过，1 个真实登录钥匙串集成测试按设计忽略。
- Intel x64 与 arm64 2.0.0 `.app/.dmg` 已生成；两个 DMG 的 `hdiutil verify` 通过，两个应用包的 `codesign --deep --strict` 通过，架构和 `CFBundleShortVersionString/CFBundleVersion` 均正确。
- Intel `.app` 已在本机启动，确认 EnvDock 进程和一个主窗口存在后正常退出；arm64 版本未在 M 系列设备上启动。
- Intel 版本空闲启动约 30 秒时，`vmmap -summary` 记录物理 footprint 29.6 MiB、峰值 30.9 MiB；这是空闲基线，不代表打开大 JSON 或执行请求时的峰值。
- 被忽略的 `login_keychain_roundtrip` 在本机尝试时等待 macOS SecurityServer 超过 60 秒后中止；普通 Rust 单元测试不再访问真实钥匙串，因此完整测试不会受此影响。
