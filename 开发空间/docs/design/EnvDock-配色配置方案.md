# EnvDock 配色配置方案 v2

日期：2026-11-22。依据 [配色知识库.md](配色知识库.md) 第 03 节「软件工具 UI 配色」、第 02 节 token 方法与附录 A.3「软件 UI 主题」。完整 CSS 见 [envdock-themes.css](envdock-themes.css)，尚未改动 `src/themes.css`。

## 1. 选型结论

EnvDock 是数据密集、长时间停留的开发者工具，按知识库的行业对应关系，选 **墨蓝专业** 作为主方案，**暖灰创作** 作为阅读型备选：

| 主题 ID | 名称 | 类型 | 直接来源 |
| --- | --- | --- | --- |
| `dark` | 墨蓝专业 · 深色 | 深色（默认） | A.3 墨蓝专业 深色 |
| `light` | 墨蓝专业 · 浅色 | 浅色 | A.3 墨蓝专业 浅色 |
| `graphite` | 暖灰创作 · 深色 | 深色 | A.3 暖灰创作 深色 |

保留现有主题 ID，不改 `ThemeMode`、不改本机偏好文件，只替换 `src/themes.css` 的颜色值。`system` 继续解析为 `light` 或 `dark`。

不选「极简单色」：EnvDock 需要区分 GET/POST/DELETE、成功/警告/错误和 JSON 语法色，纯黑白会丢失语义。不选「青绿效率」：它更适合健康与协作工具，和接口调试的冷静气质不符。

## 2. 三层色彩系统

按知识库要求，组件只消费语义层，不直接写 HEX。

| 层 | EnvDock 对应 | 说明 |
| --- | --- | --- |
| Primitive | 中性 12 阶、蓝色 10 阶、语义色阶 | 只作为原料，不直接出现在组件 |
| Semantic | `--bg`、`--panel`、`--text`、`--accent`、`--success` 等 | 主题切换只改这一层 |
| Component | `--primary-bg`、`--code-key`、`--method-get` 等 | 由语义层派生，不跨主题复用硬编码 |

中性色采用知识库冷灰 12 阶：`#FFFFFF #F7F9FC #F1F4F8 #E6EBF2 #D5DCE6 #B3BECC #8A96A8 #667085 #4A5568 #2E3947 #16202A #0B1220`。深色界面按知识库「4 层明度」：`#0B1220 → #121C2E → #182640 → #22304A`，不把背景和卡片压成同一种黑。

## 4. 代码与终端配色

代码区按知识库第 03.10 节的终端语义取值，但保持 EnvDock 原有「字段名蓝 / 字符串橙 / 数字绿 / 字面量紫 / 注释灰」分工：

| 语法 | 深色 | 浅色 | 来源 |
| --- | --- | --- | --- |
| 字段名 | `#7AA2F7` | `#1D4ED8` | ANSI Blue / Tailwind blue-700 |
| 字符串 | `#E0AF68` | `#92400E` | ANSI Yellow / amber-800 |
| 数字 | `#9ECE6A` | `#0F766E` | ANSI Green / teal-700 |
| 布尔、null | `#BB9AF7` | `#9D174D` | ANSI Magenta / pink-800 |
| 注释 | `#8CA0B8` | `#667085` | 中性 600 阶 |

不在代码区使用大面积背景色，避免和请求/响应正文的层级混淆。

## 6. 落地步骤

1. **替换主题值**：用 [envdock-themes.css](envdock-themes.css) 中 `dark`、`light`、`graphite` 三块替换 `src/themes.css` 现有同名块；共享规则与 CodeMirror 规则不动。
2. **不改主题 ID**：`preferences.ts` 的 `ThemeMode` 保持 `dark | light | system | graphite`；旧偏好无需迁移。
3. **设置面板改名**：只改显示名与缩略图，`深色 → 墨蓝深色`、`浅色 → 墨蓝浅色`、`石墨黑 → 暖灰深色`；缩略图颜色同步为新值。
4. **启动底色**：`tauri.conf.json` 的窗口 `backgroundColor` 改为 `#0B1220`，与默认主题一致。
5. **测试**：
   - 断言三套主题各含 78 个变量且变量名集合相同；
   - 将第 5 节全部对比度写成测试，低于 4.5 失败；
   - 增加 50% 缩放与灰度截图检查。
6. **回滚**：旧 `themes.css` 保留一个版本；三套主题 ID 不变，改回数值即可。

## 7. 与上一版方案的差异

- 上一版自拟了「墨蓝夜航 / 宣纸鸢尾 / 咖啡石墨」，本版直接采用知识库 A.3 的 **墨蓝专业深/浅 + 暖灰创作深**，来源可追溯。
- 深色背景从 `#141A26` 下移到知识库的 `#0B1220`，并明确 `#121C2E / #182640 / #22304A` 四层明度。
- 浅色从纸色 `#F4EFE6` 改为知识库冷灰 `#F7F9FC / #FFFFFF`，更符合开发者工具的「工具类偏冷灰」。
- 强调色由自拟 `#8FB8E8` 改为品牌蓝 `#5B8CFF`（深色）与 `#2563EB`（浅色按钮），并修正上一版浅色主题的对比度问题。
- 代码语法色改为知识库 ANSI 语义色，保留大整数、JSON 注释等现有功能不受影响。
