# M1/M2 本地接口工具实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement task-by-task. 独立模块可并行，集成与验收由主任务完成。

**Goal:** 交付可启动的 Windows 桌面开发版，完成多项目、多环境、多服务、多接口的编辑、SQLite 保存及原生 HTTP 调试闭环。

**Architecture:** React UI 经受限 Tauri IPC 访问 Rust；SQLite 是配置唯一事实来源。请求执行基于配置快照，生产确认、变量解析、取消和超时在原生层控制。

**Tech Stack:** Tauri 2、React、TypeScript、Vite、Rust、reqwest、rusqlite、Windows DPAPI。

## 范围与现状

- 起点仅有三份方案，不存在源码、Git 仓库或历史数据库。
- 开发范围仅 `D:\专用工具\接口工具\开发空间`；不修改连点器及原始提案。
- 本次优先实现可用闭环；导入导出、完整历史、文件上传、脚本和安装器属于 M3/M4。
- 已发现 Node 24、MSVC 14.44、Windows SDK；Rust 未安装，采用开发空间内隔离工具链，不改变系统默认 Rust 设置。
- 不自动提交或推送代码；在开发空间初始化 Git，所有修改留待用户审阅。

## 任务 2：SQLite 存储与秘密保护

文件：`src-tauri/src/store.rs`、`src-tauri/src/secrets.rs`、`src-tauri/migrations/001_initial.sql`。

- [ ] 先写测试：空库、CRUD 往返、重启读回、跨项目绑定、跨服务目录、重名、事务回滚与旧 revision 保存冲突。
- [ ] 测试期望：不合法保存必须失败且旧快照完整；`save(workspace)` 返回 `revision + 1`。
- [ ] 实现结构化表、外键、唯一约束、版本迁移；全工作区保存短事务，禁止磁盘保存展开的请求。
- [ ] DPAPI 保护秘密，读给 UI 的敏感值为空；保存空敏感值表示保留已有值，首次空秘密允许作为空字符串。
- [ ] 仅读供请求执行的快照可解密；不在日志/错误里包含值。
- [ ] 用临时目录验证真实 SQLite，记录测试结果。

- [ ] 实现 `prepare` 与 `execute` 分离；预览遮罩秘密，发送时解密快照。

1. 不使用 localStorage 或散落 JSON 替代 SQLite。
2. 不能把浏览器模拟效果称为桌面应用验证。
3. 不自动重试写操作，不跨环境回退，不静默明文保存秘密。
4. 页面切环境不改变已经发送请求的快照。
5. 计划、测试记录中的完成状态以实际命令输出为准。
