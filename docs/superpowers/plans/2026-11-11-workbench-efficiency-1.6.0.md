# EnvDock 1.6.0 工作台效率版实施计划

> 对应设计：`docs/superpowers/specs/2026-11-11-workbench-efficiency-1.6.0-design.md`

## 目标

在不改变请求执行协议、SQLite 结构、响应缓存和临时请求数据模型的前提下，补齐工作台高频操作：

- 最近关闭普通接口标签恢复；
- 命令面板和快捷键总览；
- 响应搜索的焦点上下文；
- 分隔条双击恢复默认比例；
- 1000×700 小窗口和现有四主题的局部适配；
- 版本、文档、发布元数据统一到 1.6.0。

## 实施顺序

### 1. 现状与测试基线

- 检查当前工作区状态、现有测试工具和组件测试模式。
- 针对要改的纯逻辑先补测试，单独运行并确认失败。

### 2. 命令与快捷键定义

- 新增 `src/lib/commands.ts`，只维护命令 ID、标题、关键词、分组、快捷键和状态说明。
- 让命令面板和快捷键总览共享同一份定义。
- 测试命令定义的唯一性、分组和快捷键展示数据。

### 3. 最近关闭标签

- 在 `useWorkbench` 增加会话级最多 20 条恢复栈。
- 记录普通项目接口的项目 ID、接口 ID、关闭前位置。
- 接入关闭当前、关闭其他、关闭右侧、关闭全部和主动重新打开时的失效清理。
- 增加恢复方法与可恢复状态，保持项目隔离、接口删除过滤和自动保存失败行为。
- 为关闭与恢复顺序、位置、焦点和失败场景补测试。

### 4. 命令面板与快捷键总览

- 新增 `CommandPalette`，支持搜索、上下键、Home/End、Enter、Esc、禁用态和焦点恢复。
- 新增 `ShortcutsDialog`，按分组只读展示共享命令定义。
- 在 `App.tsx` 注入动作执行函数，复用现有保存、页面切换、布局和侧栏状态。
- 接入 `Ctrl/Cmd+Shift+P`、`Ctrl/Cmd+Shift+T`、`Ctrl/Cmd+W`。
- 补组件和交互测试。

### 5. 搜索上下文与分隔条

- 将响应搜索快捷键限制在响应面板及其响应编辑器/工具栏上下文。
- 保持请求编辑器、JSON 工具、开发工具箱和设置使用自身查找行为。
- 给 `ResizeHandle` 增加 `onReset` 和双击恢复，保留拖拽及键盘行为。
- 补响应搜索、双击恢复和偏好独立保存测试。

### 6. 页面适配

- 使用现有主题令牌补齐命令面板、快捷键弹层和窄窗口滚动/间距。
- 不引入新的主题体系，只修正局部布局和可用性。
- 检查 1000×700、1440×900 与 dark/light/soft/dusk 四主题。

### 7. 版本与交付

- 统一更新 `package.json`、`package-lock.json`、Tauri 元数据和锁文件到 1.6.0。
- 更新 README 和 `docs/releases/v1.6.0.md`。
- 运行前端测试、Rust 测试、打包检查和生产构建。
- 汇总修改文件、兼容性、验证结果、风险和交付产物。
