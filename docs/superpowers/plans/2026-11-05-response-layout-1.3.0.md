# EnvDock 1.3.0 请求响应布局调整

**Goal:** 请求和响应底色轻微区分，响应栏在宽面板上合成一行，分隔线视觉缩为 1 像素。

**Architecture:** 仅重排 ResponsePanel 已有控件，在请求/响应容器分别覆盖 CodeMirror 背景变量，ResizeHandle 使用伪元素绘制细线。保持现有状态、事件与拖动逻辑。

**Tech Stack:** React、TypeScript、CSS、Vitest、Playwright。

**Spec:** 用户本轮两张参考截图及三项要求。

## 约束与影响

- 沿用 1.3.0，保留既有未提交修改。
- 不改 IPC、后端、数据库、偏好结构或其他临时工具编辑器。
- 保留响应环境、详情、清除、搜索、折叠、复制及 Headers 入口。
- 窄面板允许换行，不能裁掉控件。分隔线保持拖动与方向键调整。
- CSS 级联以 themes.css 为准，四主题分别配置背景，验证正文可读性。
