# Response inspection implementation plan

**Goal:** 在当前 1.0.0 中增加柔和主题、JSON 字段定位与复制、数组表格和会话响应比较。

**Architecture:** 保留 ResponsePanel → CodeEditor 调用链及原文复制。将路径、表格数据与差异算法拆为纯函数；大响应的解析与格式化放入可取消 Worker。比较基准由 App 按接口/环境持有，不写业务存储。

**Tech stack:** React 19、TypeScript、CodeMirror 6、Vitest；不新增依赖。

## 约束及已确认事实

- 版本保持 1.0.0，不安装、不发布、不推送。
- 保留未提交的 JSON 折叠改动，保留原始响应和发送逻辑。
- 用户已有主题偏好不被覆盖；新增 `soft`（雾青）主题，工具外壳低饱和、数据类型颜色明确。
- 非 JSON、空响应及截断响应有清晰降级，不将不完整数据声称为完整比较。
- 仅使用合成数据验证，不发送业务请求。

## 任务

- [x] 主题：修改 `preferences.ts`、`preferences.test.ts`、`SettingsPanel.tsx`、`themes.css`，可新增独立 Settings 测试。先测 soft 持久化与 colorScheme，保留系统主题监听和原选择。
- [x] JSON 模型：新增 `json-inspection.ts` 及测试。提供安全的 `$`/点/下标路径解析、解析后对象查找、格式化文本中的字段范围索引、数组发现与列模型。特殊键使用 JSON 字符串方括号，无 eval，无原型链访问。
- [x] 响应对比：新增 `json-diff.ts`、`ResponseDiff.tsx` 及测试、独立 CSS。新增/删除/修改使用文本标签；可忽略字段/完整路径，数组可按唯一 id 匹配；分页限制 DOM，明确超限提示。
- [x] 展示：新增 `JsonInspector.tsx`、`JsonArrayTable.tsx` 及测试/独立 CSS。字段定位自动展开目标并滚动选中；复制路径/值/对象；对象、标量、混合数组分页，按列筛选排序和检查嵌套值。
- [x] 集成：修改 `ResponsePanel.tsx`、`CodeEditor.tsx`、`App.tsx` 及对应测试。App 中按接口+环境管理一个会话基准；请求刷新不清除、上下文不串用；保持折叠、搜索与原文复制。
- [x] 性能：解析仅在正文变化时运行，Worker 处理大响应并在换正文/卸载后终止；JSON 索引按需建立，表格/差异分页、搜索高亮上限保留。
- [x] 验收：定向测试、完整 `npm test -- --maxWorkers=2`、`npm run build`；浏览器用合成数据验证雾青主题、窄面板、7525 行数组、路径定位及对比。

## 风险控制

- 深层 JSON 的 stringify/栈限制需要失败降级为原文。
- 比较基准仅当前应用会话有效，显式保存；不引入历史持久化或数据库迁移。
- 大规模比较有上限，必须提示已截取；不能显示“无变化”掩盖未检查数据。
- 编译及测试通过后再给完成结论；安装版不会自动替换。
