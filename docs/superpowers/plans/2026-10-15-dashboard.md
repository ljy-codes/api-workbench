# EnvDock 仪表盘主页实施计划

**目标：** 在当前 1.0.0 中，点击左上角 EnvDock 图标进入仪表盘，方便查看当前项目和继续调试。

**结构：** `App.tsx` 增加 `home` 页面与 Logo 按钮；`Dashboard.tsx` 只读取当前工作区并触发现有导航、接口选择和新建操作。沿用 React、TypeScript、Lucide 与现有 CSS 主题变量，不增加依赖。

## 设计与边界

- 保留原启动入口；从任何页面点击 Logo 返回仪表盘，Logo 显示当前页状态，键盘可操作。
- 保留侧栏、项目和环境选择器。切换项目时统计随之更新。
- 展示当前项目接口、服务、环境、目录四项统计；服务接口分布、HTTP 方法分布、环境绑定概览和当前项目已打开接口。
- 环境绑定概览只表示启用且有非空地址的配置覆盖情况，不代表网络可达或服务健康。
- 新建接口、配置环境、管理变量、工作区管理复用已有功能；空工作区给出创建项目入口，没有服务时给出创建服务入口。
- 返回主页不保存、不清空标签、不改变接口或环境；草稿和正在运行的请求保留在现有模型中。主页禁止 Ctrl+Enter 发送，Ctrl+S 保持原语义。
- 不增加数据库、IPC、缓存、MQ、事务或原生后端改动，版本仍为 1.0.0。

## 风险

- 大量服务和接口下使用集合和 Map 聚合统计，避免多重全量查找；列表限制首屏数量并显示总数。
- 已打开接口只代表当前会话标签，不标为持久历史或完整执行记录。
- 新页面使用独立类名和语义主题变量，避免覆盖已有工作台样式。
- 不提交、重置或撤销当前工作区已有的集合快捷操作改动。
