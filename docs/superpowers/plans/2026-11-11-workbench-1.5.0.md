# EnvDock 1.5.0 工作台界面优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在保留 1.4.0 临时请求及现有未提交改动的前提下，完成评估文档第一阶段和第二阶段中已确认的工作台操作优化，并将版本升级到 1.5.0。

**Architecture:** 继续使用现有 React 组件和 `useWorkbench` 状态模型，不改数据库、Tauri IPC、请求执行协议或临时请求流程。全局搜索快捷键由 Sidebar 管理；请求编辑器和响应面板只调整可见工具层级；标签管理由 `useWorkbench` 提供一次性批量关闭能力，RequestTabs 负责溢出入口与右键菜单。

**Tech Stack:** React 19、TypeScript、Vite、Vitest、Testing Library、Tauri 2、Rust。

**Spec:** `D:\专用工具\接口工具\EnvDock-UI更新空间评估.md`

## Global Constraints

- 保留当前工作区全部 1.4.0 未提交改动，尤其是临时请求相关文件。
- 本轮不新增、扩展、删除或重构临时请求功能。
- 不修改数据库结构、IPC 命令、请求执行协议和响应解析协议。
- 版本统一为 `1.5.0`。
- 新增行为先写测试并确认测试因功能缺失失败，再实现生产代码。
- 仅在本轮修改涉及的组件和令牌范围内调整样式，不做全仓库视觉重构。

```tsx

  expect(screen.getByLabelText('搜索接口')).toHaveFocus();

  fireEvent.keyDown(document, { key: 'Escape' });

it('在输入控件和 CodeMirror 中不拦截快捷键', () => {
  render(<Sidebar {...props} />);
  const input = document.createElement('input');
```
