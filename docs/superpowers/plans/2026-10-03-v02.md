# 0.2 增强版实施计划与接口约定

**Goal:** 在现有本地工作台上交付多标签、搜索、服务公共配置、鉴权、表单上传、cURL 与项目交换能力。

**Architecture:** 保持 React → 受限 Tauri IPC → Rust/SQLite；环境仍与服务、接口正交。先修复已有集成遗漏，再分模块实现，最后组合验证。不提交或推送 Git，不覆盖已有用户数据。

**Tech Stack:** 延续锁定的 React / Tauri / reqwest / rusqlite；原生文件对话框只由用户按钮触发。

## 共享 DTO（兼容旧 JSON）

- Service 新增 `headers?: Pair[]`、`auth?: AuthConfig | null`。
- RequestDefinition 新增 `auth?: AuthConfig | null`、`form?: FormField[]`；bodyType 增加 `form` / `multipart`。
- AuthConfig：`{ kind: 'none'|'bearer'|'basic'|'apiKey', token?: string, username?: string, password?: string, key?: string, value?: string, location?: 'header'|'query' }`。
- 请求 auth 缺省/null 表示继承服务；服务缺省/null 表示无鉴权；kind=none 显式禁用继承。
- 凭据字段 token/password/value 只允许空值或 `{{变量名}}` 引用，秘密值在变量编辑器中使用 DPAPI 保存；禁止通过 auth JSON 新增明文凭据存储。
- FormField：`{ id, key, value, enabled, kind: 'text'|'file' }`，全部字段必填。file 类型的 value 是本机文件路径；导入/导出一律清空路径并禁用文件项，用户须重新选择。
- Header：服务默认，接口同名（ASCII 不区分大小写）覆盖整个服务同名组；接口重复项仍保留。鉴权生成与手工同名 Header/Query 冲突时拒绝，不静默覆盖。
- Body=form 使用 URL 编码文本项；multipart 支持重复文本/文件项，单文件最大 10 MiB，总文件内容最大 20 MiB，只读普通文件，默认不接受符号链接。
- `engine::export_curl(&Workspace,&ExecuteInput) -> Result<String,String>` 生成脱敏的 POSIX shell cURL；只复制，不执行，用户需替换脱敏凭据和文件路径。
- `api.pickFile(): Promise<string|null>` 原生选择上传文件。
- `api.readProjectFile(): Promise<string|null>` 原生选择并读取 .json/.apiworkbench 项目文件，上限 10 MiB。
- `api.writeProjectFile(content:string): Promise<string|null>` 原生保存项目文件；路径由对话框选择，不由导入内容指定。
- `api.exportCurl(input): Promise<string>` 原生脱敏 cURL。
- `api.backup(): Promise<string>` 一致性备份到当前数据目录 backups，不接受外部 SQL。
- cURL 导入只做解析，禁止 shell 执行/命令替换/管道/重定向；未知参数明确拒绝，绝不静默改变语义。
- 项目交换格式 `{format:'api-workbench',version:1,project:Workspace}`：恰好一个项目，导入分配全新 ID，名称冲突自动加后缀，不覆盖现有项目；敏感变量值置空，已知鉴权/凭据头及敏感 Query 清除或转成待填写秘密引用。普通正文也可能含秘密，导出前必须提示检查。

## 数据库回滚与风险

迁移脚本保留在 migrations；事务失败保留原库。成功升级后若回退到 0.1，应先退出所有实例，另外保留完整 v2 数据目录，再以升级前 SQLite 一致性备份恢复到单独目录并使用 0.1；不能将新字段无损降级到 v1。DPAPI 仍绑定 Windows 用户，交换文件不是凭据备份。备份可能包含加密凭据和非秘密字段明文，按私有数据保护。
