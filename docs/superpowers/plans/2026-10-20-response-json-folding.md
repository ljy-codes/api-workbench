# 响应 JSON 折叠实现计划

**目标：** 当前 1.0.0 的响应正文可逐层折叠对象和数组，大数组不依赖编辑器完成全量语法解析；折叠显示项数，并提供全部收起 / 全部展开。

**调用链：** `App → ResponsePanel → CodeEditor → CodeMirror`。修改限定前端显示，不涉及发送、响应缓存、SQLite、凭据、环境地址或事务。

**实现选择：** 沿用 CodeMirror 虚拟滚动、行号和只读编辑器。对已验证且格式化的只读 JSON 线性扫描结构，提供折叠范围与直接子项数量；请求编辑器继续使用原有语法折叠。避免新建 JSON DOM 树或强制同步全量语法解析。

**交互：** 行号旁箭头逐层切换；工具栏收起后保留根结构，将内部对象和数组折叠，以便查看全局字段。顶层数组可直接收起。占位符显示“N 项”或“N 个字段”，点击可展开；全部展开恢复全文。原始文本及非 JSON 不显示 JSON 操作；复制始终复制原始正文。

**文件职责：**

- `src/lib/json-folding.ts`：只读格式化 JSON 的结构范围及子项计数，非递归扫描，忽略字符串内的括号和转义字符。
- `src/components/CodeEditor.tsx`：提供结构折叠服务、中文占位符和安全的折叠控制句柄；文档或模式变化时清除旧范围。
- `src/components/ResponsePanel.tsx`：JSON 工具栏按钮和句柄连接，保留懒加载。
- `src/components/editorTheme.ts`：折叠栏与占位符沿用主题变量。
- `src/styles.css`：响应工具栏允许换行，确保 280px 窄面板的折叠、查找、复制按钮均可见。
- 对应测试：真实 CodeMirror 状态、7525 项大数组、转义字符、全文不变、复制原文、搜索、文本切换和新响应重置。
