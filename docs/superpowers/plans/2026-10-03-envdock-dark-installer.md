# EnvDock 深色安装器与完整卸载 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 交付统一品牌、深色安装器、欢迎页功能概要及安全完整卸载的 Windows 安装包。

**Architecture:** 保持 Tauri/NSIS、应用标识和数据格式不变。安装器主题与业务程序隔离；完整卸载仅清理当前用户固定应用数据目录，不跟随重解析点，升级绝不清数据。保留数据卸载仍可用。私有工作区数据不进入发布物。

**Tech Stack:** Tauri 2、NSIS 3、Windows API、PowerShell 5.1、React。

## 已确认设计

- 用户于 2026-10-03 确认：对接几何 E 图标、石墨黑/深海军蓝/电光青、安装/卸载统一深色。
- 欢迎页列出多项目服务环境、环境独立请求响应、自动保存/Ctrl+S、本地存储/导入/清理。
- 完整卸载需要明确确认，清理应用管理的数据库、缓存、日志、备份；可选择保留数据。
- 不删除 Yaak、便携版源数据、用户手动导出、共享 WebView2；占用或权限失败必须报错。
- 保留防降级检查、升级数据和现有业务功能，不更改数据库 schema。
- 当前分支已有大量上一轮修改，在原目录增量修改，不重置、不将私有测试记录提交。

## 风险

- 系统文件选择器/UAC/SmartScreen 属于 Windows，不能保证跟随安装器深色，也不得关闭保护。
- 未签名程序可能有未知发布者提示。
- 数据清理不可撤销；默认保留，完整卸载需要主动选择和确认；静默卸载必须显式参数才删数据。
- 外部导出及旧便携版数据不属于安装版，刻意保留。历史迁移脚本创建的外置恢复副本由用户按脚本返回的准确路径管理，卸载器不扫描删除。
