# 环境矩阵固定列与手动排序

目标：横向滚动时固定服务名称列；通过服务行的上下箭头、环境列的左右箭头调整当前项目顺序。应用版本保持 1.0.0。

调用链：`EnvironmentMatrix` → `useWorkbench.mutate` 草稿 → 现有保存、切换自动保存 → Rust Store 同事务按数组索引写入已有 `position` → 按 `position` 加载。不涉及数据库结构、索引、请求执行、缓存或消息队列变更。

实现边界：

- 固定第一列和左上表头，使用不透明主题背景及分隔阴影，长名称可换行、悬停查看全名。
- 服务上移/下移、环境左移/右移。首尾禁用越界操作；支持键盘聚焦；忙碌、加载时禁用。
- 从最新工作区快照查找当前项目相邻元素，仅交换对应数组槽位，保留其他项目位置和顺序。
- 实体 ID、绑定地址/启用状态、接口配置、选中项目/环境不变。侧栏、环境选择器使用同一顺序。
- 排序遵循原保存机制，失败保留草稿，不新增自动写库路径。
- 根据后续反馈，将环境矩阵导航及关联环境概览的图标统一为现有图标库的圆角四宫格，保持低饱和配色。
- 导航分别采用低饱和蓝、紫、青、暖金，深浅主题使用各自颜色；选中背景继续使用中性底色。
