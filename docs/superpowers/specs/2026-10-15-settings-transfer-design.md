# EnvDock 1.0.0 设置与数据交换设计

用户已要求实施，沿用当前版本和紧凑界面。所有操作离线执行，Yaak 程序与数据不修改。

## 界面

主导航底部增加设置入口，设置对话框包含外观、布局、导入导出、本地数据。主题支持深色、浅色和跟随系统；初始使用深色。偏好在本机单独保存，不进入项目交换文件。底部状态栏显示 `著作:lxs`。

侧栏可收起/展开，请求和响应支持上下、左右分屏，保留拖动和键盘调节尺寸。布局选择与尺寸持久化，窄窗口仍可操作。编辑器保持 JSON 键、字符串、数字等分色。

## 数据交换

统一文件入口自动识别 EnvDock 旧版单项目 JSON、新多项目 JSON、Postman Collection 2.x、Postman Environment 和 Yaak 导出。导入先展示项目/环境选择，再一次性合并为新草稿，分配新 ID，禁止覆盖既有项目或执行请求。不支持的脚本等行为给出提示。

导出采用普通 JSON，支持多项目及各项目环境勾选。环境裁剪同步裁剪绑定、环境变量和请求环境配置；保留接口共享路径，保护环境隔离。沿用已有凭据脱敏和上传文件清空规则，响应缓存不进入交换文件。支持零环境项目。

文件和实体数量沿用既有上限。转换模块按需加载，不增加常驻解析器；设置关闭时不挂载交换面板。首屏继续按需加载编辑器。

## 兼容及验证

不更改数据库结构，不改变自动保存和执行链路。旧 v1/v2 交换文件继续可读。

验证主题持久化、系统主题更新、布局恢复、多项目选择、环境关联裁剪、外部格式转换、无效文件原子失败及原有测试。记录构建大小与本机测量条件，不以开发服务器数据宣称桌面性能。
