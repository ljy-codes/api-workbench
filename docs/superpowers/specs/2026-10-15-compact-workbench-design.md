# EnvDock 1.0.0 紧凑工作台

用户已确认按截图对比方案实施，继续使用当前 1.0.0 版本。

## 范围

- 缩减顶栏、标签栏、树节点、按钮与分隔条占位，保持正文可读字号。
- 删除请求区重复的面包屑、大标题、保存入口和常驻地址预览。
- 正文类型与 Body、Params、Headers、Auth、变量处于同一行；cURL、预览、超时和说明收进更多操作。
- 服务采用单行树节点，域名放到悬停提示，完整配置仍在环境矩阵。
- 响应默认只保留指标、执行环境和内容工具栏，搜索与执行详情按需展开。
- 请求与响应共用 CodeMirror JSON 配色：key 蓝、字符串橙、数字青、布尔/null 紫、标点灰。响应只读，支持行号、折叠、搜索和原文复制。

## 边界

不修改版本号、SQLite、迁移、IPC、请求引擎或工作区数据结构。不改变环境隔离、切换自动保存、Ctrl+S、Ctrl+Enter、生产确认、异步锁定、表单文件禁用和响应清理行为。保留 `docs/test.md` 的本机内容，不提交任何业务样本。

## 验收

检查常用宽度下布局和两个正文区域的颜色；测试正文类型切换、格式化、预览和保存期间锁定、搜索与原文格式、响应环境归属。前端全量回归、生产构建和安装包配置检查通过后生成同版本安装包。
