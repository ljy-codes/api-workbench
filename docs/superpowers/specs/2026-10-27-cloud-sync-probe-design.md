# 可选云同步：第一轮接入与协议验证

日期：2026-10-27。状态：用户已同意试验，本文件记录本轮验证范围；不表示已经上线云同步功能。

## 已确认需求

- 云同步为可选项，默认关闭；同步引擎和网盘适配器按需下载、运行及卸载。
- 目标支持百度网盘、夸克网盘官方授权，以及自定义 WebDAV 地址和账号。
- 首台设备可以创建文件夹，或选中授权范围内的已有文件夹，上传工作区。
- 其他设备选择同一文件夹，通过“使用云端数据”接入；接入后继续同步。
- 接口、环境、服务和目录的身份必须稳定，接入不能沿用普通导入的全新 ID 分配逻辑。
- 默认各设备保留敏感变量值、响应缓存、临时变量、本地文件路径和界面偏好。
- 云端配置须加密；网盘登录凭据和同步密码用途不同。
- 离线仍能本地使用；并发修改不得静默覆盖。

## 本轮交付

1. 查询百度、夸克当前官方接入条件，核实 Windows 支持及授权前置条件。
2. 编写独立的 WebDAV 协议试验，以本机 HTTP 服务和虚构工作区模拟两台设备。
3. 验证建目录、创建云端工作区、从已有目录接入、加密传输数据、双向更新和版本冲突。
4. 验证错误密码、认证失败、断网、上传中断、重复接入、目录已有工作区及并发提交。
5. 保存可复现命令、验证结果和真实网盘接入的剩余事项。

## 范围与兼容性

- 试验代码放入 `experiments/cloud-sync/`；不被应用入口、Vite、Cargo 或安装器引用。
- 不改 `package.json`、Rust 依赖或现有数据库结构，版本保持 1.0.0。
- 不访问真实工作区、真实网盘账号，不安装和执行第三方网盘程序。
- Node.js 仅为开发试验环境；正式可选组件需独立打包，不能要求用户预装 Node.js。
- 本轮不做主程序 UI、组件下载器、自动轮询、真实 OAuth 回调或安装包发布。
- 现有未提交的请求体复制与选区修改保持原样。

## 试验协议

- 自定义 WebDAV 仅允许 HTTPS；测试专用开关允许回环 HTTP。
- 一个用户选中的文件夹对应一个同步空间，内含公开且无业务数据的识别文件和不可变加密快照。
- 识别文件以 `If-None-Match: *` 首次创建；后续以读取到的 ETag 执行 `If-Match` 条件写入。
- 如果服务未提供可用 ETag，则拒绝启用写同步；每个客户端首次向目录发布前，以随机标记文件实际探测条件写入，拒绝只返回 ETag 却忽略写入条件的服务。
- 快照包含空间 ID、快照 ID、父版本和完整配置，用同步密码经 scrypt 派生的密钥进行 AES-256-GCM 加密。
- 身份元数据也参与完整性校验；客户端验证快照与识别文件对应关系。
- 先成功上传不可变快照，再更新识别文件；中断不会让当前版本指向半个快照。
- 客户端保留共同基础版本。仅远端修改时拉取；仅本地修改时提交；双方都修改时返回冲突并保留本地副本。
- 禁止按时间戳实施最后写入覆盖，禁止回退为没有条件的 PUT。
- 首次写入已有同步文件夹时拒绝覆盖，引导使用已有云端数据。
- 敏感值和设备专属状态在进入协议前过滤。试验不提供真实凭据同步能力。

## 重要限制

- 本地协议服务只能验证客户端行为；真实提供方是否正确实现条件写入，必须另外验收。
- 百度、夸克未必提供与 WebDAV 相同的并发控制；适配器必须独立验证，不能直接宣称具有相同一致性保障。
- 不满足并发安全能力的服务只能提供明确的手动导入/导出，不能冒充双向自动同步。
- 正式发布前还需实现应用侧事务落盘、草稿保护、凭据存储、组件签名校验及撤销授权。
- 本轮不自动提交 Git，不推送、不发布 Release、不重装本机软件。

## 第一轮验证结果

- 2026-10-27：20 项本地端到端测试通过，双设备演示完成。
- 已覆盖提交成功但响应丢失时的重试识别，以及加密后文件体积超限保护。
- 百度官方文档确认新应用访问目录与桌面回调限制；真实账号能力尚未验证。
- 夸克原生 Windows 支持与独立桌面应用接入仍未确认；没有执行官方或第三方程序。
- 按需下载扩展、主程序 UI 和真实服务接入不在本轮完成范围，不能标记为已上线。
- 代码审查发现 PUT 202 被误当成完成，已先用两项失败测试复现，再修正为只认可明确完成的 200/201/204；未确认写入时保留本地修改及原基础版本。
