# 环境矩阵与导航优化 · 2026-10-16

## 已确认事实与方案

- 用户反馈横向滚动后服务名称消失，并要求服务上下、环境左右可手动调整；继续使用 1.0.0。
- 后续反馈要求环境导航图标更柔和，各功能图标颜色稍有不同。
- `EnvironmentMatrix` 按当前项目筛选服务和环境，单元格通过服务 ID、环境 ID 关联绑定。
- SQLite 已按 `position` 加载环境和服务，保存时在同一个事务内将数组索引写入 `position`，保留原 revision 乐观锁。
- 第一列及左上表头使用 sticky、不透明主题底色和分隔阴影；服务名可换行，悬停可查看全名。
- 行头提供上下箭头，列头提供左右箭头。禁用首尾越界、加载与忙碌状态操作，按钮可键盘聚焦。
- 从最新工作区快照交换当前项目内相邻实体对应的数组槽位，不改变其他项目位置、实体 ID、绑定、请求配置及选中环境。
- 环境图标统一为图标库已有圆角四宫格，无新增依赖。导航用低饱和蓝、紫、青、暖金区分，选中底色保持中性。
