# EnvDock 1.8.1

发布日期：2026-11-17

## 本次修复

- 修复直接填写有效 Bearer Token 时输入框被标红、鉴权配置未更新，导致请求实际发送空 Token 并返回“用户无权限”的问题。
- 鉴权凭据支持直接填写文本，也支持使用 `{{变量名}}` 引用。
- 继续拒绝花括号混用、未闭合变量引用和控制字符，避免把格式错误的内容发送出去。
- 原生请求执行、工作区保存和前端编辑校验保持一致；自测场景可直接在鉴权配置中填写 Token。

## 兼容性

- 沿用原应用标识、本机数据目录和 SQLite 工作区结构，无数据库迁移。
- 请求、响应、变量、环境和接口配置格式保持兼容。
- 版本文件统一升级为 `1.8.1`：npm、Tauri、Rust crate 及锁文件一致。

## 验证

- `npm test -- --run src/components/FrontendV02.test.tsx`
- 覆盖直接 Bearer Token 写回、变量引用兼容、非法凭据拒绝和原生请求头生成。
- Rust 测试需本机安装可用 Rust 工具链；当前开发环境未发现 `cargo`、`rustc` 或 `rustup`。
