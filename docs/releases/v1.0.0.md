# EnvDock 1.0.0

更新日期：2026-10-15。首个正式交付版本，版本号保持 1.0.0。

## 功能概要

- 本地离线保存：项目 → 服务 → 接口，可区分环境，无需账号和云端工作区。
- 环境隔离：各环境分别保存服务域名、请求配置和最近响应；接口路径共用。项目和环境颜色可配置。
- 自动保存：切换项目、环境、接口时保存，支持 Ctrl+S；Ctrl+Enter 发送请求。
- 紧凑工作台：精简顶栏、请求配置和响应操作；JSON 字段名、字符串、数字等分别着色。
- 外观设置：浅色、深色、跟随系统，即时切换并在本机记住。
- 布局设置：侧栏展开/收起、请求和响应上下/左右分屏，支持拖动和记忆尺寸。
- 导入导出：自动识别 EnvDock、Postman、Yaak 的受支持格式；先预览，再勾选项目和环境导入，导出为普通 JSON。
- 常用 HTTP 调试：Query、Headers、Body、鉴权、变量、表单和 multipart 文件、cURL 及响应搜索/折叠。
- 数据清理：清理响应缓存，可选择清空请求正文，保留接口定义；最近响应按接口与环境隔离保存并限制空间。
- Windows 安装器：缺少 WebView2 时自动尝试下载和安装；卸载可选择保留数据或明确确认后完整清理。
- 页脚作者信息：`著作:lxs`。

应用运行与数据保存均在本机。首次补装 WebView2 需要联网；调用接口时按用户配置连接目标服务。

## 兼容范围

- 保持 1.0.0 的应用标识与原本机数据目录，不需要新增数据库迁移。
- 旧 EnvDock v1/v2 单项目文件继续可读；新多项目 JSON 需要当前版本读取。
- 支持 Postman Collection v2.0/v2.1、Environment，以及受支持的 Yaak JSON/完整引用 YAML。
- 单独的 Postman Environment 导入为新项目，不自动合并已有集合。Yaak YAML 需包含所引用的工作区与父模型。
- 导入不会执行脚本、动态函数或自动发送请求；不支持的脚本、WebSocket/gRPC 等会在预览中提示。
- 导出裁剪未选环境，不导出响应缓存，并对已知凭据脱敏。自由正文和普通变量仍应自行检查，导出文件不能作为完整凭据备份。
- MIT 是源码许可，当前 Windows EXE 未进行 Authenticode 数字签名。
