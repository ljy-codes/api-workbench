# EnvDock v1.0.0

首个正式编号的 Windows x64 安装版。EnvDock 是纯本地 API 调试工作台，无需云端账户，不上传工作区数据。

项目原创代码采用 MIT License（Copyright (c) 2026 ljy-codes），完整条款见源码根目录 `LICENSE` 和 Release 附件 `LICENSE.txt`。第三方组件继续适用各自许可证。MIT 不是 EXE 数字签名，当前安装包仍未签名。

**2026-10-04 安装修订：保持版本号 1.0.0，替换同一个 Release 的安装包与校验文件。已下载旧安装包的用户请重新下载，并以本页新 SHA256 为准。**

## 功能概要

- 多项目、多服务、多环境管理；服务域名按环境配置。
- 接口方法与路径共用，请求配置及最近一次响应按环境独立保存。
- 切换项目、环境或接口自动保存，支持 Ctrl+S。
- 项目与环境支持自定义颜色，降低环境误选风险。
- 支持变量、Headers、Bearer/Basic/API Key、JSON/文本/表单请求和文件上传。
- 支持项目文件、cURL 导入与脱敏导出，响应查看、搜索及格式化。
- 本地 SQLite 存储，敏感变量与响应缓存使用 Windows DPAPI 保护。
- 可清理响应缓存及请求正文；响应缓存有容量限制。
- 原创图标、深色安装/卸载向导，欢迎页包含功能概要。

## 下载与安装

下载 `EnvDock-1.0.0-windows-x64-setup.exe`，按向导安装。

- 仅为当前 Windows 用户安装，支持修改程序目录。
- 附件提供使用说明、SHA256 校验清单、第三方许可及可选的旧便携版迁移脚本。
- 未签名，Windows 可能显示未知发布者。请核对来源和 SHA256，不要关闭安全防护。
- 新装、重装、升级均自动检测 WebView2 Runtime；已安装时不重复下载。
- 缺失时从微软官方下载并静默安装：先尝试在线引导安装器，失败后切换 x64 完整安装器，各最多两次；网络下载超时也会重试。
- 执行前校验有效微软签名，安装后重新检测，不能只凭退出码判成功。此步骤需要联网，完整备用包较大，请耐心等待安装详情中的进度。
- 依赖准备成功前不移除旧程序。自动尝试耗尽后才提供重试、微软手动安装页面或退出；需要重启、安装进程超时分别提示，避免启动重叠安装。静默/被动模式返回非零错误码。
- 不要求安装 Node.js、Rust、编译器或 SDK；不下载替换 Windows 系统 DLL。
- EXE 作为可选 Release 附件提供，不纳入源码仓库。

## 卸载与数据

- 默认卸载保留工作区；主动选择“完全卸载”并确认后才清理应用专属目录。
- 升级始终保留数据，不触发完整清理。
- 不删除 Yaak、旧便携版、应用数据目录外的导出/迁移恢复副本或共享 WebView2。
- 完整清理不可恢复，重要数据请先导出到应用数据目录之外。
- 数据目录和 schema v3 沿用开发版本。应用版本 1.0.0 不代表数据库格式回退。
- 附件迁移脚本仅适用于同机同一 Windows 用户；使用前关闭程序，目标已有数据时拒绝覆盖。

## 已知限制

- Windows x64；尚未完成跨 Windows 版本、高 DPI、无 WebView2 环境的完整矩阵验证。
- 暂不支持 OAuth 流程、脚本、批量测试、完整历史、Postman/OpenAPI 导入及可配置代理。
- 应用发送的 API 请求不自动跟随重定向或重试；仅缓存每个接口与环境的最近一次响应。此限制不指安装器的依赖下载。
- 普通 Body、普通 Headers 和普通变量不会自动加密；导出前仍需检查业务隐私。
- 系统安全提示和系统对话框不保证采用安装器深色主题。
