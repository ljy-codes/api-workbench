# EnvDock 1.6.0

构建日期：2026-11-11。工作台效率与窄窗口适配版本。

## 本版更新

- 新增最近关闭标签恢复。普通项目接口标签关闭后会进入当前应用会话的恢复栈，最多保留 20 条；恢复时回到原项目和关闭前的位置。临时请求不进入恢复栈，删除接口或自动保存失败的标签不会留下无效恢复记录。
- 新增命令面板，使用 `Ctrl/Cmd+Shift+P` 打开，可按名称、关键词和分组搜索工作台命令，并支持键盘上下选择、回车执行和 `Esc` 关闭。
- 新增快捷键总览，可从命令面板打开，统一展示当前命令与快捷键，避免命令面板和帮助说明各自维护。
- 增加 `Ctrl/Cmd+Shift+T` 恢复最近关闭标签、`Ctrl/Cmd+W` 关闭当前标签的快捷键。
- 分隔条支持双击恢复默认分屏比例，同时保留拖拽和键盘调整能力。
- 响应搜索限制在响应面板上下文内，避免在请求编辑器、JSON 工具箱、开发工具箱和设置页面操作时误触发。
- 补充命令面板、快捷键弹层和窄窗口布局样式，适配 1000×700 小窗口及现有四套主题。

## 兼容性

- 保留原有应用标识、数据目录、SQLite 结构、IPC 命令、请求执行协议、响应缓存和临时请求模型。
- 最近关闭标签仅保存在当前应用会话内存中，不写入数据库或 `localStorage`；退出应用后恢复栈清空。
- 关闭标签只关闭工作区视图，不删除接口、草稿、响应缓存或项目配置。
- 版本元数据统一为 `1.6.0`，可直接使用现有安装器覆盖升级。
