# EnvDock 1.4.0

构建日期：2026-11-10。Windows x64 安装版。

## 本版更新

新增「临时请求」：没有项目、服务和环境，也能直接使用完整 HTTP/HTTPS 地址调试接口。

- 左侧闪电图标进入临时请求；空工作区欢迎页提供「临时调试」按钮。
- 已有接口未选择环境时，也可从提示旁直接进入临时调试。
- 支持 GET、POST、PUT、PATCH、DELETE、HEAD、OPTIONS，多个临时标签可分别编辑和发送。
- 支持 Params、Headers、Bearer / Basic / API Key、JSON / Text / Form URL / Multipart 正文及超时设置。
- 临时鉴权直接填写凭据；不需要先建立秘密变量，不继承当前项目的变量、服务公共 Header 或鉴权。
- 复用响应正文、Headers、搜索、JSON 收起/展开、字段定位、数组表格及执行诊断。
- Ctrl/Cmd+Enter 发送当前页请求；临时页不会因 Ctrl/Cmd+S 保存普通工作区。
- 支持取消请求、关闭单个标签及关闭全部；关闭运行中的临时标签会请求取消。取消不代表服务端回滚。

## 使用

1. 点击左侧「临时请求」，或者欢迎页的「临时调试」。
2. 输入完整地址，例如 `http://127.0.0.1:8080/api/users?page=1`。
3. 按需设置方法、Params、Headers、Auth 或 Body，然后点击发送。
4. 可继续新建临时标签；返回「接口工作台」使用原有的项目与环境流程。

地址栏中的 Query 和 Params 中启用的参数都会发送。请求无需工作区变量解析，正文中的 `{{文字}}` 按字面内容发送。

## 兼容性与范围

- 沿用原应用标识及 `%LOCALAPPDATA%\ApiWorkbench` 数据目录，无数据库结构迁移。
- 普通接口的环境归属、生产确认、变量引用、自动保存及最近响应缓存继续沿用原行为。
- 临时标签自然保留在当前应用内存中，切换页面可继续使用；关闭标签或应用后不会恢复。本版没有增加系统级无痕或数据擦除机制。
- 临时请求不加入普通项目的时间线，不导出到项目文件；主题和分屏偏好仍沿用原有保存方式。
- 实际发送需要桌面版；浏览器中可编辑预览界面。
- 支持完整 HTTP/HTTPS URL；地址中不允许用户密码或 fragment。TLS 校验保持开启，不自动跟随重定向；暂不支持自定义代理或 WebSocket。
- 临时响应比较基准按标签独立保留，切换标签或页面可继续比较；关闭标签后清除。沿用最多 8 份、合计 16 MiB 的会话基准限制。
