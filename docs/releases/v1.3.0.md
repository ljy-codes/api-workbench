# EnvDock 1.3.0

发布日期：2026-11-05。Windows x64 安装版。本次包含此前尚未发布的 1.2.0 工具扩展及 1.3.0 的完整改进。

## 本版更新

- **临时 JSON 工具箱**：格式化与搜索、可选去 null、展开或压成一行、双栏对比、转义还原、字段提取；支持忽略字段、按 id 匹配、去重及 CSV / SQL IN 输出。保留大整数和精确小数，关闭窗口清空临时数据。
- **临时开发工具箱**：URL 编解码、UTF-8 Base64、Unix 时间戳、JWT 结构查看和 SQL 字符串列表。支持将 `"1","23"` 或 `1,2,3` 转成 `'1','23'` 或 `'1','2','3'`，保留前导零、重复项和精度，单引号按 SQL 标准转义。
- **请求时间线与排查**：当前会话内查找和筛选执行记录、比较两次响应、恢复为未发送草稿；新增网络阶段诊断和可预览、脱敏导出的 HTML 问题排查包。
- **OpenAPI 导入与更新预览**：离线读取 OpenAPI 3.0 / 3.1、Swagger 2.0 的受限 JSON / YAML 请求子集，预览后选择创建新项目或更新服务，应用为未保存草稿。更新保留本地请求内容、鉴权及环境覆盖；文档移除项仅提示。
- **配色与布局**：新增中间明度的暮蓝主题，四种主题适配；导航、仪表盘与工具页增加柔和分区色。请求与响应正文使用轻微不同的底色；响应状态、耗时、大小、页签、格式、操作及环境合并为一栏，窄面板自动换行。
- **细分隔线**：视觉线宽 1px，保持 5px 拖动范围和方向键调整；响应复制、搜索、收起/展开、Headers 和执行详情入口保留。
- **发布前防护修订**：排查包统一隐藏请求 JSON 敏感字段及文本表单值在响应、Header、步骤中的回显；无法完整收集秘密或超出预算时省略正文。OpenAPI 导入及更新阻止含模板变量的 Query 参数名。

## 支持范围与限制

- 临时 JSON 和开发工具仅在窗口内存处理，关闭清空，不写工作区或浏览器存储，也不调用网络。主题和布局偏好仍按原方式保存在本机。
- 请求时间线仅保留当前应用会话；原有“最近响应”缓存继续按原方式存于本机，二者不是同一种历史记录。
- JWT 工具只解码结构，不验证签名。SQL 工具只转换文本，不执行 SQL；特殊反斜杠规则需按目标数据库方言处理。
- OpenAPI 是受限请求导入器，不是完整规范验证器；不获取外部引用，不导入响应模型，不自动配置鉴权，也不会发送接口。已有环境覆盖不会被共享模板新增字段自动改写。
- 排查包会处理已知敏感字段，但无法识别任意业务正文中的秘密；分享前应检查预览。网络诊断只报告实际测得的阶段，不虚构 DNS / TCP / TLS 细分时长。
- 此次没有生成新版 macOS 安装包，不包含云端同步功能；未将真实业务接口联调计作发布验收。
- 附件不包含用户数据库、真实接口数据、环境凭据或本机备份。源码与第三方许可随仓库和交付包提供。
