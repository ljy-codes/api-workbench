## 使用

- 设置 → 外观 → 暮蓝：中间明度的灰蓝外壳和编辑器，保留 JSON 键、字符串、数字、字面量的独立配色。已有主题与分屏偏好继续沿用，不自动迁移主题。
- 左侧扳手 → 临时开发工具箱 → SQL 字符串列表：粘贴后点击「转为单引号列表」，再点击「复制结果」。

| 输入 | 输出 |
| --- | --- |
| `"1","23"` | `'1','23'` |
| `1,2,3` | `'1','2','3'` |
| 逐行粘贴的带双引号 ID，可有末尾逗号 | 合并成一行单引号列表 |
| `001,900719925474099312345,001` | `'001','900719925474099312345','001'` |
| `"O'Reilly"` | `'O''Reilly'` |

支持英文/中文逗号、CRLF/LF、单引号列表、JSON 双引号字符串和一维数组。忽略未引用的空白项，保留明确引用的空字符串、前导零、顺序、重复项与原有精度。双引号字符串按 JSON 解码；格式错误拒绝整次转换，原文保留。

仅生成 SQL 标准字符串字面量列表，不执行数据库查询，不提供数据库方言适配；在 MySQL 等具有特殊反斜杠规则的数据库中，含反斜杠的值需按目标数据库规则处理。嵌套数组/对象不在支持范围。输入和输出各限 1 MiB UTF-8，修改输入会撤下旧结果；切换工具或关闭窗口清空数据及撤销历史，无网络、存储、IPC 或额外依赖。
