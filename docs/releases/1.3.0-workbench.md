## 临时开发工具箱

点击左侧扳手图标：

| 工具 | 支持内容 | 约定 |
| --- | --- | --- |
| URL 编解码 | URL 组件编码、单层解码 | `+` 保持加号，不当作表单空格 |
| Base64 编解码 | UTF-8 文本与标准 Base64 | 要求规范 `=` 填充，不处理任意二进制文件 |
| Unix 时间戳 | 秒/毫秒转日期、ISO 转时间戳 | 日期必须带 `Z` 或 `±HH:mm`；显示 UTC 与本地时区 |
| JWT 结构查看 | Header、Payload 原始 JSON | 未验证签名，不判断登录权限或过期，不支持 JWE |

输入和输出各限 1 MiB UTF-8。错误保留原文，修改输入或时间单位会撤下旧结果并禁用复制；主动转换后才生成新结果。复制由用户点击触发。

工具数据、状态、搜索和撤销历史只在组件内存中，切换工具或关闭窗口清空，不写入 SQLite、浏览器存储或工作区，不调用网络。JSON 按钮可转到现有 JSON 工具，原四个 JSON 页签保留。

## OpenAPI 导入与更新预览

入口：「设置 → 导入导出 → OpenAPI 导入 / 更新」，工作区管理中的导入导出区也可打开。

1. 粘贴 JSON/YAML 或选择本地文件，文档上限 10 MiB。
2. 选择「创建新项目」或「更新已有服务」。更新需指定项目和服务。
3. 点击「预览变更」，查看新增、变化、无变化、文档已移除/未列出、已阻止及具体字段说明。
4. 勾选要应用的接口。更新项默认不选；不支持、歧义及文档移除项不可应用。
5. 点击「确认所选为草稿」，检查后按原方式保存。预览和确认不会发送请求；确认不会自动保存。

新项目包含服务、导入环境和所选接口。首个 tag 映射一级目录；支持的根服务器地址作为新服务绑定，缺失或无效时留空。

更新按转换后的 `method + path` 精确匹配，例如文档 `/users/{id}` 对应工具 `/users/{{id}}`。不会把不同参数名称的路径猜测成同一个接口。

| 数据 | 更新行为 |
| --- | --- |
| Query/Header 新字段 | 补到共享模板 |
| 已有名称、目录、参数值和启用状态 | 保留本地内容，差异列出提示 |
| 鉴权、Token、正文、表单、超时 | 保留本地内容 |
| 全部环境覆盖、变量和绑定地址 | 原样保留；共享模板新字段需在已有环境覆盖中手动补齐 |
| 文档未列出的本地接口 | 仅提示，保留接口 |
| 相同方法和路径匹配多个接口 | 阻止该项，需人工处理 |
| 预览之后工作区变化 | 拒绝应用，必须重新预览 |

离线受限解析 OpenAPI 3.0/3.1、Swagger 2.0 的请求子集，支持基本标量参数、JSON/text 正文及有预算限制的本地 JSON Pointer 引用。不是完整规范验证器或双向同步。

不会获取外部引用、执行脚本、导入响应模型或自动配置鉴权。多个请求媒体类型、复杂组合/条件 Schema、对象或数组参数序列化、二进制/表单正文、路径/操作级 servers 等不受支持，预览会提示或阻止。YAML 别名、自定义标签、重复字段和不安全结构会拒绝。

已知凭据字段会清空；普通名称、路径、正文仍可能包含业务数据，应在导入和分享前检查。

## 兼容性与回退

- 应用标识、安装目录规则与 `%LOCALAPPDATA%\ApiWorkbench` 数据目录保持原样。
- 本次不增加 SQL、数据库迁移、IPC 接口或网络依赖；不涉及 Redis、MQ 或服务端事务。
- 新导入和更新沿用现有草稿与保存流程。确认前取消不会修改工作区；确认后未保存的内容可以按原草稿流程处理。
- 旧版 1.2.0 安装包及交付目录保留。本轮不执行本机卸载、安装、GitHub 推送或 Release 发布。
- 自动化浏览器采用合成工作区和模拟 Tauri IPC，不读取真实业务数据，不能替代真实桌面文件选择和企业环境验收。
