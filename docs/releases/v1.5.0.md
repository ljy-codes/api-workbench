# EnvDock 1.5.0

构建日期：2026-11-11。Windows x64 工作台优化版本。

## 本版更新

- 接口搜索支持 `/` 和 `Ctrl/Cmd+K` 快捷键，输入框、代码编辑器等可编辑区域不会被抢占；按 `Esc` 清空搜索并失焦。
- 请求地址的脱敏预览常驻显示，复制脱敏 cURL 和超时秒数提升为可见工具按钮，详细超时毫秒数仍可在更多操作中调整。
- 响应面板拆分为响应状态和响应操作两层，正文、Headers、格式化、搜索、复制、JSON 收起/展开、字段定位、数组表格、响应对比及执行详情继续保留。
- 请求标签支持“全部标签”入口，方便在标签较多时快速切换；标签右键菜单支持关闭当前、关闭其他和关闭右侧标签。
- 批量关闭标签在一次工作区上下文切换中完成自动保存，避免连续关闭标签时重复保存或产生竞态。
- 新增工作台尺寸、间距、字号和圆角令牌，标签菜单、请求工具栏和响应双层工具栏沿用现有主题语义颜色。

## 兼容性

- 保留原有应用标识、数据目录、数据库结构、IPC 命令、请求执行协议和响应缓存行为。
- 保留 1.4.0 的临时请求功能；本版没有新增、删除或改造临时请求流程。
- 关闭标签只关闭工作区视图，不删除接口、草稿、响应缓存或项目配置。
- 版本元数据统一为 `1.5.0`，可直接使用现有安装器覆盖升级。安装前仍建议保存普通接口草稿并退出旧程序。
