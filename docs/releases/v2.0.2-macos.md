# EnvDock macOS 2.0.2

日期：2026-11-26。

## 变更

- 采用 B「双舱桥」图标：暖石墨底、米白请求舱、铜橙响应舱；应用内、macOS 和 Windows 资源由同一母版生成。
- macOS 同步 main 的完整共享功能与最近源码精简，保留环境隔离、鉴权、请求执行、JSON 工具、导入导出、历史、对比和排查报告。
- 保留 macOS 登录钥匙串加密、测试内存密钥、系统路径别名处理与本机 Rust 工具链适配。
- 源码统一位于仓库根目录，保留 main / windows / macos 三条长期分支。
- 新增跨分支源码与品牌资源一致性检查，系统实现允许按平台变化。

## 兼容性

Bundle ID、登录钥匙串服务、本地数据目录、SQLite schema 和 IPC 契约保持兼容。本次没有数据库迁移。

## 交付边界

Intel x64 与 arm64 DMG 分别构建。Intel 在本机 macOS 13.7.8 验证；arm64 交叉构建不等于 M 系列实机启动验证。

应用使用 ad-hoc 签名，未使用 Apple Developer ID 或公证。Windows 源码及新图标同步到 windows 分支；本 Mac 不构建或宣称实测 Windows 安装器。

最终验证结果见本版交付目录中的 VERIFICATION.json。
