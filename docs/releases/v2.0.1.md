# EnvDock Windows 2.0.1

发布日期：2026-11-23

## 本次变更

- Windows 同步 macOS 2.0.0 的共享工作台能力：全局快捷键监听使用稳定引用，避免编辑过程中反复注册窗口级监听。
- 工作台项目、环境、接口、请求和关闭标签等派生数据使用记忆化计算，减少编辑与响应处理期间的重复扫描。
- 增加本地渲染异常恢复页，支持重新加载应用和复制诊断信息；诊断只保存在本机，不增加遥测。
- 测试初始化兼容 Node 25 实验性 Web Storage，并统一 Testing Library 异步等待超时。
- 浅色主题的注释色、顶部工作台文字和弱化文字调整为更容易识别的低对比度方案。
- 启动失败显示本地诊断信息，保留 Windows WebView2 和本地数据目录语义；WebView2 默认缓存目录失败时继续使用恢复目录。
- CSP 增加对象、基础 URL、框架嵌入和表单提交限制。
- 增加 `npm run check:version`，统一检查 npm、Tauri、Rust crate 和锁文件版本。

## Windows 平台兼容性

- 保留 Windows DPAPI、WebView2、NSIS 安装器、PowerShell 构建与卸载脚本。
- 保留 `%LOCALAPPDATA%\ApiWorkbench` 数据目录、`ApiWorkbenchData` 便携目录和现有 SQLite 工作区结构。
- 不引入 macOS Keychain、WebKit、`.app` / `.dmg` 或 macOS 系统目录别名规则。
- 不新增数据库迁移，不改变 IPC、请求配置、响应缓存、变量和鉴权数据结构。
