## 兼容性与限制

仅局部界面与样式变动，沿用请求执行和响应数据流程，不修改数据库、IPC、版本号或依赖。全局临时工具编辑器配色保持原有配置。窄面板或长状态文字会增加工具栏高度，以保留功能入口。

源码验收阶段未运行原生 Rust 回归。后续依用户授权构建 Windows NSIS 安装包并执行本机替换，安装与数据保留结果保存在本机验收记录。GitHub 发布阶段补做完整前端和 Rust 回归，最终附件与支持范围见 [1.3.0 发布说明](v1.3.0.md)。
