# EnvDock 1.1.0 · 临时 JSON 工具

日期：2026-11-03

## 已确认需求与实现边界

- 请求体「格式化 JSON」主动清理对象 null 字段与对象 / 数组尾随逗号，输入、原文复制、保存和发送不触发清理。
- 独立窗口默认保留 null，允许选择移除 null；提供展开格式化、单行压缩、按模块收起、搜索和复制。
- “模块”按对象、数组的结构折叠，保留对象根字段供审查；搜索可以展开遮挡命中的模块并定位。
- 工具内容、选项和搜索只在组件内存中；关闭销毁，清空同时销毁编辑器和撤销历史。不连接存储、IPC 或网络。
- 数组 null 保留以维持索引；空对象不连带删除；false、0、空字符串保留。

## 文件与职责

- `src/lib/json-format.ts`：共用格式化逻辑，仅容忍尾随逗号；先验证，再按原始 token 排版，避免 Number 精度损失和字段重排。
- `src/lib/json-search.ts`：普通文本、不区分大小写的搜索；最多保留 1000 个高亮范围。
- `src/components/JsonToolsDialog.tsx`、`JsonToolsSearch.tsx`、`json-tools.css`：临时工具窗口、搜索与样式。
- `src/components/CodeEditor.tsx`：增加可选结构折叠和主动文本替换，解决输入后 200 ms 内格式化、折叠、搜索的时序问题。
- `src/components/Dialog.tsx`：允许额外样式类，保留原对话框默认尺寸。
- `src/components/RequestEditor.tsx`：格式化接入共用逻辑，保留之前的原文复制功能。
- `src/components/editorTheme.ts`、`src/styles.css`：保留之前的选区显示修复与请求体复制样式。
- `src/App.tsx`：左侧导航入口与懒加载；窗口打开及加载期间拦截工作区保存 / 发送快捷键。
- `package.json`、`package-lock.json`、`src-tauri/Cargo.toml`、`src-tauri/Cargo.lock`、`src-tauri/tauri.conf.json`：版本元数据同步升级 1.1.0；`scripts/test-packaging.mjs` 增加锁文件版本一致性检查。
- `vite.config.ts`：保留默认测试排除规则，额外排除未接入产品的 `experiments`；`README.md` 更新当前版本和操作说明。
- `json-format.test.ts`、`json-search.test.ts`、`JsonToolsDialog.test.tsx`、`App.json-tools.test.tsx`、`RequestEditor.format.test.tsx`：覆盖格式化边界、搜索、存储隔离、关闭清空及请求编辑器接入。

## 兼容性与风险

- 不改变应用标识、工作区模型、SQLite 表及数据目录，无数据库迁移。
- 唯一主动改变请求数据的动作是用户点击请求体格式化；格式化去 null 可以使用编辑器撤销恢复。
- 复制当前全部原文，包含折叠部分；剪贴板内容由用户系统管理。
- 不支持猜测修复连续逗号、缺引号、注释等错误；错误不覆盖正文。
- 展开排版限制嵌套深度 512 层；超过时可压缩单行。搜索超过 1000 处时显示 `1000+` 并仅导航前 1000 处。
- 保留先前请求体复制修复及独立云同步试验；云同步原型未接入产品。
