# EnvDock 1.7.1

构建日期：2026-11-13。修复 1.7.0 自定义窗口操作失效的补丁版本。

## 修复

- 补齐 Tauri 2 主窗口的 `close`、`minimize`、`toggle-maximize` 和 `start-dragging` 权限。
- 修复安装版窗口无法拖动、最小化、最大化或关闭的问题。
- 主窗口启动时优先使用原 WebView2 缓存目录；如果该目录被占用，自动切换到本次启动的恢复目录，避免空白窗口或直接退出。

## 兼容性

- 保留应用标识、数据目录、SQLite 结构、IPC 命令、请求执行协议、响应缓存和请求体注释能力。
- 恢复目录只存放 WebView2 缓存，SQLite 工作区仍使用原来的 `ApiWorkbench` 数据目录。
- 仅修复桌面窗口交互权限，不改变请求编辑、发送和本地数据行为。
- 可直接覆盖升级 1.7.0。

## 验证

- 打包配置回归测试通过。
- TypeScript 检查与 Vite 生产构建通过。
- 前端全量测试通过。
- Windows x64 NSIS 安装器构建通过。
