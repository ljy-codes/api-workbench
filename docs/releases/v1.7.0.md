# EnvDock 1.7.0

构建日期：2026-11-13。JSON 请求体注释、编辑器配色和无品牌标题栏优化版本。

## 本版更新

- JSON 请求体支持 `//` 行注释和 `/* ... */` 块注释，注释字段可以保留在编辑器中，便于临时禁用字段和分析请求结构。
- 发送请求、请求预览和 cURL 生成前会剥离 JSON 注释，注释字段不会进入实际请求；注释中的变量不会参与解析、渲染或解密。
- JSON 编辑器支持 `Ctrl+/` 或 `Cmd+/` 批量注释、恢复选中行，空行和字符串中的 `//` 不会被误处理。
- JSON 格式化、去除空值和折叠逻辑支持注释，注释内容保留在编辑器及格式化结果中。
- 按参考图左侧的视觉方向调整代码区配色：深蓝黑编辑器底色，字段名使用亮蓝色，字符串使用橙色，数字使用绿色，布尔值和 `null` 使用粉色；其他主题同步补充注释颜色。
- 移除原生顶部标题栏和 `EnvDock · API Workbench` 标题，将最小化、最大化、关闭按钮放入应用内顶栏。
- 收紧顶栏操作区间距，降低辅助控件对比度，让请求体与响应体编辑区域成为视觉重点。

## 兼容性

- 保留原有应用标识、数据目录、SQLite 结构、IPC 命令、请求执行协议、响应缓存和临时请求模型。
- JSON 注释是编辑器层能力，发送链路仍然提交标准 JSON；不使用注释的现有请求行为保持不变。
- Form、Multipart、Text 请求体行为未改变。
- 版本元数据统一为 `1.7.0`，可直接使用现有安装器覆盖升级。
