## 同版本新增：请求排查

- **请求时间线**：左侧独立入口，按当前项目查看已提交执行的记录，可搜索、筛选环境和结果、删除、清空；保留提交时的当前环境模板，后续编辑不会改写历史。最多 50 条 / 16 MiB 序列化 UTF-8 数据，按完成顺序淘汰；单条超限跳过提示。仅应用会话内存，关闭应用或清理全部响应缓存时清空。
- **响应比较**：勾选两份完整 JSON 响应即可查看字段差异，较早执行作为基准，复用精确数字比较和检查上限。失败、截断或非 JSON 响应明确提示不能比较。
- **恢复草稿**：先自动保存当前草稿，失败则停止；恢复共享方法、路径及原环境普通配置，不发送请求。沿用当前鉴权、敏感 Header / Query、变量及服务公共配置；缺少当前值的历史字面量凭据清空禁用，变量占位符可保留。临时变量不恢复，上传文件需重新选择；原接口、环境或服务归属变化时拒绝覆盖。
- **网络诊断**：结果分类、总体 / 本地准备 / 响应头等待 / 正文接收耗时，以及实际取得的 HTTP 版本、远端地址、接收字节。响应头等待包含连接、TLS 和上传，暂不独立测量 DNS / TCP / TLS。取消、超时及失败保留已采集指标，未开始阶段不伪造数值。
- **HTML 问题排查包**：填写现象与步骤，按需选择请求正文、响应正文和响应 Headers，三项默认关闭。递归隐藏常见敏感字段、URL 查询值、已知秘密、变量及上传路径；无法安全解析的正文省略。先核对文本预览，再通过桌面原生对话框保存同一份静态 HTML，限制 10 MiB，无脚本或外部资源，不自动上传。修改选项使旧预览失效。
- cURL 仅为脱敏复现模板，需自行补齐配置和凭据。自动脱敏不能判断所有普通业务文本，分享前需核对预览。
- 新增详细发送命令，保留旧发送 API；响应新增可选诊断字段，旧加密缓存继续读取。应用标识、数据目录、schema、无重试 / 无重定向 / TLS 校验 / 2 MiB 响应预览策略保持。

## 新增能力

JSON 工具在原格式化页面上增加双栏对比、转义还原和字段提取。页签可用鼠标或方向键切换；当前窗口内保留各页草稿，关闭窗口清空全部内容。

### 双栏对比

- 左右粘贴任意 JSON，点击「开始对比」，查看新增、删除、修改及字段路径。
- 支持格式化两侧、交换左右、清空两侧。
- 复用响应对比引擎，支持忽略字段 / 路径、按唯一 id 匹配数组、每页 50 项差异。
- 修改原文后旧结果失效；解析失败提示对应输入，不覆盖原文。
- 双栏格式化沿用比较的输入、嵌套及节点上限，展开后每侧最多 100 万字符；超限时两侧原文均保留，成功格式化的内容可继续比较。
- 比较保留长整数、精确小数；不同数字写法的同一数值视为相等，例如 `1`、`1.0`、`1e0`。
- 比较上限为 1000 项差异 / 20000 个检查节点，达到限制明确标记部分结果，不宣称两份数据一致。

### 转义还原

- 「转为字符串」把任意文本编码为一层 JSON 字符串，包含外侧双引号。
- 「还原字符串」要求输入带双引号的有效 JSON 字符串，每次只还原一层。
- 原文和结果分别显示，可复制结果或用结果继续处理。
- 修改原文后旧结果失效；非法转义或输入并非字符串时给出提示并保留原文。

### 字段批量提取

- 与格式化页面共用源 JSON，支持 `$`、`.field`、数组下标、`[*]`、引号字段。
- 示例 `$.data.list[*].id` 提取列表内每条记录的 id。
- 输出格式：JSON 数组、逐行文本、单行标准 CSV、SQL `IN (...)`。
- 可选择结果去重；字符串和数字不混淆，相等数字按精确数值去重。
- SQL 字符串的单引号转义；复合对象不能直接生成 SQL IN；工具不连接或执行 SQL。
- 修改源数据、路径或输出选项后需重新提取，不能复制旧结果。
- 修改或清空后忽略未完成复制操作的旧提示；恢复先前原文也需重新提取。
- JSON 数组结果可主动替换工具源文，随后仍可在编辑器中撤销。
- 仅支持以上路径子集，不支持过滤表达式、递归查询、脚本或动态求值。

## 保留能力及兼容性

- 原格式化、压缩、模块折叠、搜索、复制和可选去 null 规则保持。
- 请求体主动格式化仍仅移除对象 null 字段及尾随逗号；数组 null、false、0、空字符串保留。
- 不改变应用标识、用户数据目录、SQLite 表结构或鉴权规则，没有数据库迁移；后续请求诊断扩展的兼容边界见上文。
- 本次没有接入云同步或增加运行依赖；新工具随入口按需加载。
- 原会话响应对比接口保持兼容，只扩展内部精确数字识别和展示。

## 数据生命周期

- 工具输入、搜索、转换结果、提取规则及对比基准仅保存在当前窗口内存。
- 不连接工作区存储、IPC、网络、localStorage、sessionStorage 或文件。
- 关闭窗口销毁全部工具；清空销毁对应编辑器及其撤销历史。
- 复制由用户主动触发，系统剪贴板按操作系统机制管理。
- 超限或无法解析时明确提示，保留输入，不静默截断成完整结果。
- 新增精确解析 / 提取及字符串转换输入最多 100 万字符，输出最多 200 万字符。精确 JSON 最多 128 层、5 万节点；提取最多 1 万个匹配，路径最多 128 段 / 4096 字符，单个数字最多 4096 字符。
