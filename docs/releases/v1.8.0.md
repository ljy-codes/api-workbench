# EnvDock 1.8.0

发布日期：2026-11-16

## 本次更新

- 外观主题收敛为四种：浅色、深色、跟随系统、石墨黑。
- 新增石墨黑调色板：工作台外壳使用低亮度中性黑，请求体使用偏蓝黑，响应体使用石墨灰，便于快速区分编辑区。
- 保留 JSON 键、字符串、数字、布尔值及 `null` 的独立语法色，正文和行号对比度保持可读。
- 请求体与响应体之间继续使用 1px 分隔线，默认与悬停颜色降低强调，键盘聚焦仍提供明显反馈；5px 拖动热区不变。
- 旧版本保存的 `soft`（雾青）和 `dusk`（暮蓝）偏好启动时回退为 `dark`，不会改写原有本机偏好存储。

## 兼容性

- 沿用原应用标识、本机数据目录和 SQLite 工作区结构，无数据库迁移。
- 请求、响应、变量、环境和接口配置格式保持兼容。
- 版本文件统一升级为 `1.8.0`：npm、Tauri、Rust crate 及锁文件一致。

## 验证

- `npm test -- src/components/SettingsPanel.theme.test.tsx src/lib/preferences.test.ts`
- 覆盖四主题入口、石墨黑即时应用与持久化、旧主题回退、请求/响应底色区分、语法色对比度和布局设置保留主题。
