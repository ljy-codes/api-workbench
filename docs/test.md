- 无 Redis、MQ、云端同步或远程日志；测试不调用生产接口。

## 清理与失败边界

- 默认保留数据；完整清理需明确选择与确认，静默清理只接受独立精确 `/PURGE`。
- `/PURGE=0`、前缀变体及小写参数不触发删除；`/UPDATE` 优先保留数据。
- 仅处理当前用户三个固定应用数据目录；链接、文件占用、只读与异常路径均有回归。
- 失败中止卸载并保留程序与卸载入口；不把部分清理报告成成功。
- 合成 NSIS 夹具仅在脚本副本中替换特殊目录解析，其余清理逻辑不变。
- 所有完整清理测试均使用合成根目录；未在真实用户目录执行 purge。
- 测试本身的 dot-source 入口测试也只传入合成脚本副本，避免入口回归误删真实数据。

## 评审、风险与未覆盖项

- 独立规格、安装代码及清理安全评审已通过，无已知阻断遗留。
- 清理不是事务，权限或并发变化可能造成部分清理；操作前应备份。
- 安装包未签名；系统安全提示和系统对话框可能不跟随深色主题。
- 未覆盖完整交互删除、跨 Windows 版本、高 DPI、无 WebView2 和完全无缓存构建矩阵。
- 不上传本机导入数据、Yaak 数据、数据库、凭据、工具链、日志或生成缓存。
