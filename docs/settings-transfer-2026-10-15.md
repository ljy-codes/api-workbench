# EnvDock 1.0.0 设置与导入导出验收

日期：2026-10-15。保持 1.0.0。本轮仅使用合成数据、临时数据库和回环测试服务。

## 已确认事实

- 业务工作区继续使用原 SQLite 与 DPAPI 链路，数据库 schema 和 IPC 工作区模型不变。
- 新偏好仅在本机 `envdock.preferences.v1` 保存，内容为主题、侧栏及分屏布局，不包含请求数据。
- 导入先解析预览，确认后合并为新草稿；不覆盖已有项目，不执行脚本或发送请求。
- 多项目导出同步裁剪环境绑定、变量、独立请求配置，并沿用已知凭据脱敏与文件路径清空。
- 保留未提交的既有修改。实现验收阶段不处理真实 Yaak 数据，不发布 GitHub，不修改已安装程序或业务数据库。

## 兼容与风险

- 旧 EnvDock v1/v2 单项目文件继续可读；新多项目 JSON 需要当前新版读取。
- Postman Environment 单文件导入为新项目，不自动合并已有集合。Yaak 同步 YAML 需包含完整引用模型。
- 支持常用 HTTP 配置，不支持脚本、完整 OAuth、WebSocket/gRPC 或任意第三方扩展；预览提示被忽略的内容。
- 已知凭据会脱敏；自由正文、路径、名称及普通变量仍可能含业务信息。导出不是包含完整凭据的备份。
- 本轮不涉及数据库 DDL、迁移、索引或回滚 SQL。偏好损坏/存储不可用时使用默认设置或内存设置。
- 未做桌面启动耗时、峰值内存的定量基准；不宣称具体速度和内存指标。
